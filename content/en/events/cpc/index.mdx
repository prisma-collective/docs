## Purpose
The purpose of this project is to deliver decision-grade regional market intelligence to Cardano Product Committee.

We do this with a local-first approach, delivering 1 global-level interface containing 3 publications. Each publication curates data generated from field excursions. Regional hubs will be selected to act as counterparties conducting local due dillegence ([primary research](/en/events/cpc/executing/terminology/primary-research)) and developing engagements with local stakeholders, for a given estimated set of regionally-appropriate emerging technology use-cases.

Each publication makes that visible _as_ decision support for the client technology provider, Cardano.
