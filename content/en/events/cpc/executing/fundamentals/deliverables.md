# Deliverables

## Core Decision Outputs

| Deliverable | Format | Content Summary |
| :---- | :---- | :---- |
| Market Prioritisation Matrix | Spreadsheet + narrative summary | At least eight candidate regional clusters scored across ten RARF dimensions, with evidence source, confidence level, and Go / Conditional-Go / Monitor / No-Go recommendation per cluster |
| Regional Entry Playbooks | Document section per priority region (at least three playbooks) | Per region: leading use case, partner archetype, regulatory pathway, infrastructure prerequisites, milestone sequence, key risks, adoption metrics, and action recommendation |
| Use-Case Viability Assessment | Table + narrative analysis | Per region: comparison of candidate use cases on problem severity, Cardano fit, alternatives, stakeholder demand, dependencies, and adoption pathway. Rejected use cases documented with reasons |
| Regulatory Landscape Summaries | Narrative + source appendix per priority region | Decision-oriented summaries identifying relevant bodies, constraints, permissions, uncertainty levels, and where local counsel is required |
| Counterparty and Partner Access Map | Table / access register | Roles, named or archetypal counterparties, access status (interviewed / warm access / referred / desk-identified / hypothetical), confidence level, and recommended next action |
| Infrastructure Prerequisite Assessment | Prerequisite status matrix | Per playbook: stablecoin, off-ramp, wallet UX, mobile/offline, privacy, identity, delivery capacity, compliance artifacts, SLA requirements — each classified as Met / Partially Met / Unmet / Unknown / Dependent on Another Workstream |
| Cardano Adoption Signal Standard (CASS) | Framework document + classification table | Definitions for four CASS tiers; classification of all identified signals; examples of strong, moderate, weak, and misleading signals by use case; recommendations for funding triggers and stop conditions |
| Research-to-Action Roadmap | Roadmap document + executive memo | Recommended next steps with go/conditional-go/no-go calls, dependencies, owner archetypes, milestone sequence, and risk levels. Distinguishes immediate, medium-term, and dependency-gated opportunities |
| Executive Decision Memo | Short memo (max 8 pages) | Top recommendations, rationale, evidence confidence, key tradeoffs, and immediate decisions required by the Product Committee |
| Cross-RFP Handoff Memo | Memo / table | Maps findings that belong in RFP 01, 02, 03, 06, 07, 08 or other workstreams; explains why each finding is a handoff; specifies requested action from receiving workstream |

## Supporting Research Outputs

In addition to the core decision outputs, the research will produce: methodology appendix; interview guide and respondent screener; anonymised interview notes or summaries where consent is given; regional evidence workbook; regulatory citation appendix; RARF scoring workbook; confidence and limitations register; risk register; data-source inventory; and glossary.

## Public and Community-Facing Outputs

A public summary will be produced, excluding confidential or sensitive findings. It will include: methodology overview; key regional findings; evidence caveats and confidence levels; publishable market prioritisation overview; publishable recommendations; and a description of the RARF and CASS frameworks for community use. The public summary will not expose respondent identities, sensitive government or regulatory views, or commercially sensitive partner information.
